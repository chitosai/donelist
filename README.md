# Done List

你有没有这样的经历：
生活中有太多细碎的事情，一旦做完我们就立刻忘记了。我们明明觉得每天都忙前忙后，到了月末、季末、年末，要回顾，要写总结时，却总是脑袋空空，完全想不起过去一段时间我们究竟都做了些什么。
反正我是这样。

所以我让 ChatGPT 帮我制作了这个快速记录工具。打开页面、输入一句话、回车，就可以毫无负担地把当下的想法、或者刚刚做完的事记录下来。
之后可以打开月历视图，帮助你回忆起最近的一切。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
pnpm install
pnpm dev
```

浏览器访问终端显示的本地地址。

## 验证与构建

```bash
pnpm test
pnpm build
pnpm preview
```

## 数据结构

每条记录包含稳定 UUID，以及 `happenedAt`、`createdAt`、`updatedAt` 三个 ISO 时间字段。页面通过 `RecordRepository` 接口访问数据；未来增加服务器时，可以新增 `ApiRecordRepository` 而无需重写界面。

注意：本服务使用 IndexedDB 储存数据，数据仅保存在当前浏览器内，如需跨浏览器访问数据请使用页面底部“数据工具”中的导出和导入功能。
